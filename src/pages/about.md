# About

I'm Shivakumar, an **Android Frameworks Engineer** with 6 years of experience working on the Android platform since the start of my career.

This site is a technical reference and notebook covering the Android architecture end to end, from the Linux kernel up to the application framework.

## Focus areas

**Kernel and boot**
- Linux kernel for Android: GKI, device tree, drivers, power management
- Boot flow: bootloader, verified boot, `init`, Zygote and system startup

**Native layer and HAL**
- Bionic, native libraries and native daemons
- Hardware abstraction: HIDL, AIDL and vendor interfaces, Project Treble
- Graphics, display and media stack: SurfaceFlinger, HWC, Gralloc, audio and camera pipelines

**Runtime and framework**
- Android Runtime (ART): DEX, JIT/AOT compilation, garbage collection
- Binder IPC and system services
- `system_server` and core services: ActivityManager, WindowManager, PackageManager, PowerManager
- App process lifecycle, Zygote, and the framework APIs apps depend on

**Security**
- SELinux, application sandboxing and permissions
- Verified boot, keystore and platform security model

**Platform engineering**
- AOSP build system: Soong, Blueprint, Make
- Partitions, APEX modules, A/B updates and OTA
- Debugging and performance: logcat, Perfetto, tombstones, dumpsys

## How the site is organised

- **[Docs](/docs/intro):** structured, layer-by-layer technical write-ups of the Android architecture.
- **[Blog](/blog):** shorter engineering notes, including experiments, debugging sessions and lessons learned.
